# NCKH — Markdown bundle từ Phase 1 đến Phase 12.2

Đây là bộ các file `.md` đã được tạo/gửi trong quá trình làm đề tài.

## Gợi ý đặt vào project

Bạn có thể đặt nguyên thư mục này vào:

```text
NCKH/
└── docs/
    └── research_notes/
        ├── phase01/
        ├── phase02/
        ├── ...
        └── phase12/
```

Các file trong đây là **tài liệu nghiên cứu / kế hoạch / diễn giải kết quả**, không phải output model.

### Vai trò nhanh theo phase

- Phase 1: literature review, research gap, frozen research design.
- Phase 2: dataset decision.
- Phase 3: cleaning/audit policy.
- Phase 4: EDA plan.
- Phase 5: feature-selection plans.
- Phase 6: baseline plan.
- Phase 7: diversity + ensemble plans.
- Phase 8: controlled tuning protocol.
- Phase 9: final holdout protocol.
- Phase 10: statistical protocol + final evidence/RQ answers.
- Phase 11: final tables/figures planning, captions, results-ready synthesis.
- Phase 12: Results draft + Discussion draft.

## Lưu ý

`research_decisions_log` và `research_task_board` có bản theo Phase 1 và Phase 2 nên đã đổi tên để không bị ghi đè.
