<h2 id="why-manimgx">Why ManimGX?<a class="headerlink" href="#why-manimgx" title="Permanent link">&para;</a></h2>
<p><strong>An API for 3D video in the age of agents.</strong> Your agent writes Python using
<a href="https://www.manim.community">Manim CE's API</a>.
ManimGX's Rust + wgpu engine renders the MP4, blazingly fast.</p>
<ul>
<li><strong>Fully statically typed.</strong> Keyword arguments and <code>.animate</code> chains included.</li>
<li><strong>2D and 3D together.</strong> Surfaces, meshes and moving cameras alongside text, equations
  and plots.</li>
<li><strong>Runs in the browser.</strong> <code>npm install manimgx</code>. <a href="https://pyodide.org">Pyodide</a> runs
  Python in a Web Worker; WebGPU renders the scene.
  <a href="/user-guide/rendering/#embed-in-a-web-page">Embed a scene</a> with no render server.</li>
<li><strong>Agent feedback.</strong> <a href="/user-guide/rendering/#inspect"><code>manimgx inspect</code></a>: storyboards and 2D layout checks, at play endings or times you choose.</li>
<li><strong>Text and math.</strong> Write LaTeX or Typst. No LaTeX installation needed.</li>
<li><strong>Speech in sync.</strong> <a href="/user-guide/sound-and-voice/">Match animations to spoken words</a>
  with <code>self.say()</code>.</li>
</ul>

<h2 id="on-the-shoulders-of-giants">On the shoulders of giants<a class="headerlink" href="#on-the-shoulders-of-giants" title="Permanent link">&para;</a></h2>
<p><a href="https://www.3blue1brown.com">Grant Sanderson</a> created
<a href="https://github.com/3b1b/manim">Manim</a>. ManimGX targets the API of
<a href="https://www.manim.community">Manim Community Edition</a>, the widely used
community-maintained fork.</p>
<p>The Rust renderer uses <a href="https://wgpu.rs">wgpu</a> for native GPU rendering and WebGPU in
the browser. Its 3D lighting is adapted from Google's
<a href="https://github.com/google/filament">Filament</a>: physically based materials,
image-based lighting, ambient occlusion, bloom and AgX tone mapping.
<a href="https://typst.app">Typst</a> typesets text and math, with
<a href="https://github.com/mitex-rs/mitex">mitex</a> translating LaTeX input to Typst.
<a href="https://www.videolan.org/developers/x264.html">x264</a> encodes native video exports as
H.264; <a href="https://ffmpeg.org">FFmpeg</a> decodes imported audio, using
<a href="https://opus-codec.org">libopus</a> for Opus.</p>
<p><a href="https://pyodide.org">Pyodide</a> runs Python scenes in a browser worker. Linux wheels
bundle <a href="https://mesa3d.org">Mesa</a>'s lavapipe for Vulkan rendering on the CPU when no
suitable GPU is available.</p>
