### Safe author-local cleanup

1. `git status --short`; commit/stash real user edits before pulling.
2. `git pull --ff-only origin main` removes the four already-deleted tracked intermediates from the working tree.
3. Run `python -X utf8 tools/clean_local_workspace_safe.py --dry-run` to preview **only untracked Python/tool cache files** in allowed code/document directories.
4. If acceptable: `python -X utf8 tools/clean_local_workspace_safe.py --apply`. The cleaner excludes `results/`, `data/`, `.research_memory/`, virtualenvs, model artifacts and all tracked files.
5. `git status --short` and `git diff --check`. Do not run `git clean -fdx`, `git reset --hard`, force-push or deletion outside NCKH.

This is deliberate to retain ability to recover exactly.
